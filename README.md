# ⚡ AutoML Data Analyst Platform

An intelligent AutoML + Data Analytics platform built with Python that enables users to upload datasets, automatically perform exploratory data analysis (EDA), preprocess data, train multiple machine learning models, compare performance, and generate actionable insights.

---

# 🚀 Features

## 📂 Dataset Upload
- Upload CSV or Excel datasets
- Automatic dataset validation
- Detect missing values and datatypes

## 📊 Automated EDA
- Statistical summary
- Correlation heatmaps
- Distribution plots
- Missing value analysis
- Outlier detection
- Feature importance visualization

## 🧹 Data Preprocessing
- Missing value handling
- Label encoding
- One-hot encoding
- Feature scaling
- Train-test splitting

## 🤖 AutoML Training
Automatically trains multiple machine learning models:

### Classification Models
- Logistic Regression
- Random Forest Classifier
- Decision Tree Classifier
- K-Nearest Neighbors
- Support Vector Machine
- Naive Bayes
- Gradient Boosting
- XGBoost (optional)

### Regression Models
- Linear Regression
- Random Forest Regressor
- Decision Tree Regressor
- SVR
- Gradient Boosting Regressor
- XGBoost Regressor (optional)

## 📈 Model Evaluation
### Classification Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

### Regression Metrics
- MAE
- MSE
- RMSE
- R² Score

## 🏆 Best Model Selection
- Automatically selects the best-performing model
- Displays leaderboard ranking

## 📑 Insight Generation
- Business insights
- Correlation analysis
- Important features
- Data quality observations

## 📥 Export Options
- Download trained models
- Export predictions
- Export EDA report
